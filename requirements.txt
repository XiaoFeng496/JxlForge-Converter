# JxlForge Converter 依赖清单
# 安装: pip install -r requirements.txt
# 用 ~=（兼容发布段）而非 == 或 >=：
#   - 不用 >=：那是「库」的语义（声明最低兼容）。本项目分发打包 exe，且本文件还被
#     setup.py（218 行）与 install_deps.sh（84 行）当作安装清单消费，用 >= 会让
#     不同时间装环境的人拿到不同 Qt，GUI 类 bug 无法复现。
#   - 不用 ==：写死会漏掉同 minor 的补丁修复。
#   - ~=6.11.3 等价 >=6.11.3,==6.11.*：可自动吃到后续 6.11 补丁，又不跨到 6.12。
#     下限取 6.11.3 而不是 6.11.2：本机与打包环境现在都是 6.11.3，且 v0.3.0 的
#     包正是在 6.11.2 环境上混进了 6.11.1 版样式插件（见下方「不要混装」）。
# ⚠️ 不要混装：PySide6 / PySide6-Essentials / PySide6-Addons / shiboken6 四个包的
#    版本必须完全一致，升级要用 --force-reinstall 整套换（pip 升级时不会清理旧版
#    残留的插件 DLL，会导致 Qt 主库 6.11.3 配 6.11.1 的 qmodernwindowsstyle.dll，
#    按钮外观、下拉框样式都会静默变样）。打包脚本会在构建前后各扫一遍版本，
#    发现同一包里出现两个 Qt 版本就直接中止。
# ⚠️ 迁移计划：6.11 非 LTS（标准支持止 2027-03-17），6.12 才是 LTS（止 2031-09-30）。
#    Qt 6.12.1 计划 2026-11-12 发布，届时改为 ~=6.12.1（避开 .0 初期 bug）。
#    升级属有意识的操作：需跑 tools/run_tests.py + 真机目视浅/深主题（offscreen 测不出），
#    再重打包 + selftest；不要混进功能提交。
PySide6~=6.11.3
Pillow>=10.0
# 删除原文件功能：移入系统回收站（Windows 上 send2trash 走 IFileOperation 原生后端，
# 需 pywin32 提供 COM 支持；缺失时 send2trash 会回退到不可靠的 legacy 后端）。
send2trash>=1.8
pywin32>=306; sys_platform == "win32"

# 不链 libx265 的 pillow-heif 精简版，体积更省），缺失时程序会提示安装、不影响其他格式。
# 打包版已带入解码链（libheif+libde265），无 HEVC 编码器（libx265），故只能解码、不能编码回 HEIC。
